MNIST digit classifier · 50,890 parameters

Supported architecture: Flatten → Linear(784,64) → ReLU → Linear(64,10). Upload a float32 PyTorch state_dict, up to 2 MB.

Prepare the real MNIST data and train your first model locally:

uv run --locked python -m weightforge.mnist --download --epochs 3

Then select runs/mnist.pt. Validation uses 1,000 reserved training examples; final evaluation uses 2,000 test examples. Imported models must respect those split boundaries.

Only this registered architecture is supported for imported models. Random sparse search may improve validation, make no change, or overfit; final test performance is reported separately.
