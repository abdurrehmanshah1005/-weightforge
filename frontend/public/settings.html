LOCAL · NO API KEY

Guided calibration

Uses validation prediction errors to suggest an output-bias correction. Works with XOR and the supported MNIST model. No backward pass.

Useful for probability bias; it does not repair arbitrary hidden representations.

Try guided calibration →
LOCAL · REPRODUCIBLE

Random search

Samples a visible weight coordinate and a bounded delta using a seed. A simple baseline for evaluating other proposers.

An experiment may retain no edits. That is a valid measured outcome.

Try random search →
CONFIGURATION REQUIRED

OpenAI proposals

A configured model receives bounded weight samples, validation diagnostics and recent decisions. It returns one JSON edit.

API charges apply. The run requires consent; holdout data and credentials are never in its prompt.

SERVER-SIDE SETTINGS

Enable the optional LLM.

Copy .env.example to .env and set these values. Choose an account model supporting structured JSON outputs.

OPENAI_API_KEY=your-key
WEIGHTFORGE_LLM_MODEL=your-model-id

Restart the backend after changing its environment. Credentials stay on the backend and are not entered in this page.

DEPLOYMENT

Two services. One workspace.

The frontend serves the product and proxies API requests. The Python backend validates, evaluates and stores your experiments. Only the frontend port is exposed locally.

docker compose up --build -d --wait
This distribution targets a single-user local workspace. Public hosting needs authentication, TLS and upload process isolation before deployment.
